Google Sheets Connection

Must start with https://script.google.com/macros/s/ and end with /exec.
Multi-PC Visibility Note
Every PC that opens this application must have the Google Apps Script Web App URL saved in Settings (or configured as DEFAULT_SHEET_URL in app.js) so all computers connect to the same Google Sheet & Google Drive.
